# Privacy (implemented scope)

Sessions, imported text/transcripts, memory records, and search index are stored in a SQLCipher-encrypted database. A random database key is DPAPI-protected for the current Windows user. Migration to another Windows account or machine is not provided. Microphone capture, VAD, faster-whisper transcription, Piper speech synthesis, and audio-file transcription run locally. Audio stays in process memory during live recognition and is not uploaded or persisted as raw audio. First-time setup downloads speech model/voice weights to the local data directory; the weights are software assets, not user recordings. The transcript, recent session messages, current profile, selected approved memories, and system/method prompts are sent to the configured text LLM (DeepSeek by default) to generate replies. Provider-side processing/retention of that text is outside this application's control. Setting `privacy.cloud_processing_allowed: false` blocks cloud-dependent session start/resume and memory extraction; local audio-file transcription/import remains available. Context payload sections have configurable approximate-token bounds; the estimate uses characters and is not an exact provider tokenizer count. Provider errors are converted to generic messages without retaining the SDK exception as a displayed exception chain; this does not prove that all runtime output or third-party SDK internals are free of sensitive data. No telemetry or third-party error reporting is configured. `psyche export PATH` creates an unencrypted JSON export that the user must protect. `psyche delete-local-data --confirm` removes local database files but does not currently remove separately stored model weights, guarantee physical erasure, or remove provider copies. Transcript retention controls, exact payload inspection/redaction, real HTTP payload inspection, and provider-side deletion are not implemented.
