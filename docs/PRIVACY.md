# Privacy (implemented scope)

Sessions, imported text/transcripts, memory records, and search index are stored in a SQLCipher-encrypted database. A random database key is DPAPI-protected for the current Windows user. Migration to another Windows account or machine is not provided. Live voice PCM frames are streamed to the configured transcription provider and are not persisted locally; transcripts, recent session messages, the current profile, selected approved memories, and system/method prompts are sent to the conversation provider. Generated text is sent to TTS for synthesis. Provider-side processing/retention is outside this application's control. `psyche import-audio` uploads a selected file only after explicit interactive confirmation; the transcript is stored locally, not the raw audio. Setting `privacy.cloud_processing_allowed: false` blocks cloud-dependent session start/resume, audio import, and memory extraction; no local model adapter is implemented. Context payload sections have configurable approximate-token bounds; the estimate uses characters and is not an exact provider tokenizer count. No telemetry or third-party error reporting is configured. `psyche export PATH` creates an unencrypted JSON export that the user must protect. `psyche delete-local-data --confirm` removes local data files but cannot guarantee physical erasure or remove provider copies. Transcript retention controls, exact payload inspection/redaction, and provider-side deletion are not implemented.
