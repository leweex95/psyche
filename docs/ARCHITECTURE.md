# Architecture (implemented scope)

The single-process Typer CLI loads YAML plus environment overrides, enforces the cloud-processing setting, constructs database/provider services at the command boundary, and passes them into `ConversationOrchestrator`. The orchestrator persists the user turn, applies deterministic safety overrides, then assembles safety/methodology policies, a bounded current profile, source-attributed ranked approved memories, and a bounded recent-history window with the current turn last. Stored profile/memory evidence is placed in a separately labeled user-role context message, not mixed into system policy. Context limits use a conservative character-based token estimate; provider tokenization can differ. SQLCipher stores sessions, messages, source documents, memories, provenance, profile versions, and the FTS index in one encrypted database.

Text and experimental voice sessions share the orchestrator. Voice capture feeds local VAD and faster-whisper on-device transcription after each utterance; the transcript then enters the same conversation path. DeepSeek is the default text-only LLM provider. The LLM streams sentence-sized text to local Piper synthesis and a bounded PCM playback queue. On barge-in, only complete sentences whose audio was consumed by the player are recorded as interrupted. Audio never leaves the device; transcripts and bounded conversation context are sent to DeepSeek. Local models and hardware still require live acceptance.

The import CLI stores UTF-8 text/Markdown and confirmed audio transcripts. Optional provider extraction creates source-quoted candidates that remain pending; the memory CLI supports review, search, correction, relationship annotation, evolution, profiles, and forgetting. Methodology behavior is prompt-guided, safety phrase checks are deliberately limited, and no clinical quality or efficacy is claimed.
