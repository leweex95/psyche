# Safety (initial baseline)

Psyche is a supportive reflection tool, not a clinician, diagnostic instrument, or emergency service. System/method prompts prohibit diagnosis, fabricated history, dependence-promoting behavior, discouraging human support, and intensive trauma exercises. A small deterministic phrase check routes several explicit imminent-harm statements to immediate-support guidance, avoids that acute script for a few directly negated forms, and redirects common diagnosis requests while allowing a user to report an existing diagnosis without being refused. The streamed voice orchestration path is tested to bypass the provider for a matched acute phrase. These rules inspect only the current utterance: they are not comprehensive, context-aware, or reliable enough to establish safety, and missed or misunderstood language remains possible. They do not cover all ambiguous suicidal language, delusional/paranoid beliefs, manic symptoms, trauma disclosures, dependency, or responses to corrections. Imported content and memory are explicitly treated as data rather than instructions. Deterministic regression tests are not clinical validation; independent clinical review and broader adversarial evaluation are required before any public deployment.
