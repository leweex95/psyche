# Safety (initial baseline)

Psyche is a supportive reflection tool, not a clinician, diagnostic instrument, or emergency service. System/method prompts prohibit diagnosis, fabricated history, dependence-promoting behavior, discouraging human support, and intensive trauma exercises. They also direct the model not to affirm unverified paranoid beliefs, not to label or diagnose possible manic symptoms, to let the user set the pace after trauma disclosures, to accept corrections, and to prioritize immediate support when danger may be present. A small deterministic phrase check routes several explicit imminent-harm statements to immediate-support guidance, avoids that acute script for a few directly negated forms, and redirects common diagnosis requests while allowing a user to report an existing diagnosis without being refused. The streamed voice orchestration path is tested to bypass the provider for a matched acute phrase. These rules inspect only the current utterance: they are not comprehensive, context-aware, or reliable enough to establish safety, and missed or misunderstood language remains possible. Deterministic regression tests are not clinical validation; independent clinical review and broader adversarial evaluation are required before any public deployment.
