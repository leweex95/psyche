# Voice status

Psyche's audio path is local-only. Microphone capture and WebRTC VAD run on-device; completed utterances are transcribed by faster-whisper on CPU; replies are synthesized by Piper and played locally. No captured or imported audio is sent to DeepSeek or another provider, and raw PCM is not retained in the database. The recognized transcript is stored with the session and, for a reply, sent as text with bounded conversation context to the configured LLM (DeepSeek by default).

Install the Python 3.13-compatible dependencies with `pip install -e ".[voice]"`. Run `psyche voice setup` to download and initialize the configured faster-whisper model and Piper voice. The model weights are downloaded from their model hosts to `%USERPROFILE%\.psyche\models` by default; those downloads are model assets, not user audio. First-run setup may need internet access and disk space. Model files are outside the encrypted database and are not removed by `psyche delete-local-data`.

The STT implementation processes a completed VAD utterance as a batch. It does not currently produce partial captions, and should not be described as streaming recognition. Piper synthesizes each sentence locally before playback; the LLM itself streams text. Speech capture/VAD remain active during response generation and playback so new speech can interrupt. Only complete sentences confirmed played are stored as delivered; interrupted or failed replies retain only the completed spoken prefix and are marked accordingly. Echo cancellation is not implemented; headphones are recommended.

`psyche audio check` lists local input devices and reports aggregate per-channel and downmixed signal levels without retaining audio. `psyche session start --mode voice` starts the experimental live path. Local transcription accuracy/speed, intelligible playback on the selected headset, interruption behavior, latency, and the 30-minute run still require hands-on acceptance. The previous OpenAI Realtime/TTS path was removed; OpenAI credentials are not needed for speech.
